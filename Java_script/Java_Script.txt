Introduction to JavaScript:
============================


--JavaScript (JS) is one of the most popular programming languages in the world.

--Initially, JavaScript was created to make web pages interactive. 

--Before JavaScript, web pages were mostly static, meaning users could only view content but could not interact with it dynamically.

Using JavaScript, developers could:

Respond to button clicks
Validate form inputs
Show alerts and notifications
Hide or display HTML elements
Change webpage content dynamically
Create animations and interactive user interfaces

Because of these capabilities, JavaScript became the language of the web.

var Keyword:
------------

--Before ES6, var was the only way to create variables.

Example:

	var name = "Ratan";

	console.log(name);

--Although var still works, it has several problems and is generally avoided in modern JavaScript development.


Problem 1: Redeclaration Allowed:

--The same variable can be declared multiple times.

	var name = "Ratan";

	var name = "Rahul";

	console.log(name);

Output:

Rahul

--This can accidentally overwrite existing data and introduce bugs.

--Imagine a project with thousands of lines of code where another developer unknowingly redeclares the same variable.


Problem 2: Function Scope Instead of Block Scope:

--This is the biggest problem with var.

--var keyword is the function scoped but not the block scope.

--A variable declared using var inside a function will act as a local variable, we can not access it outside that function.

--But we declare a variable using var keyword inside a block { } then that variable will be leaked outside that block also.


Block Scope Example

A block is any code written inside:

{
    
}


Examples:

if(true){

}

for(){

}

while(){

}


Example using var:

if(true){

    var age = 25;

}

console.log(age);

Output:

25

--Even though age was declared inside the if block, it is still accessible outside.

--This behavior is usually not desired.


Another Example:

for(var i=1;i<=3;i++){

}

console.log(i);

Output:

4

--The variable survives outside the loop block.

--The variable leaks outside the block.

--This often causes unexpected bugs in large applications.



let keyword:
-------------

--To solve the above var keyword related problem let keyword is introduced in ES6.


Example1:

Not Allowed.

let name = "Ratan";

let name = "Rahul";

Output:

SyntaxError

This helps prevent accidental bugs.

Example2: 

if(true){

    let age = 25;

}

console.log(age);

Output:

ReferenceError

The variable is accessible only inside the block.

This is the desired behavior.

Extra tips: using the + operator
===========


String + Anything: Results in string concatenation.
Number + Boolean: Coerces booleans to numbers, then performs numeric addition.
Null + Number: Coerces null to 0 and performs numeric addition.
Undefined + Number: Results in NaN (Not a Number).
Array + Array: Result in String(both array will be joined as a string)
Object + Object: Result in String (objects are converted to "[object Object]")

JavaScript Type Conversion (Type Coercion):
==========================================

--Type Conversion (also called Type Coercion) is the process of converting a value from one data type to another.

--JavaScript is a loosely typed language, which means it can automatically convert values between different data types whenever required.

There are two types of type conversion:

1. Implicit Conversion (Automatic Coercion)
2. Explicit Conversion (Manual Coercion)


1. Implicit Type Conversion (Automatic Coercion):
--------------------------------------------------

--JavaScript automatically converts values from one type to another based on the operation being performed.

String Conversion:
------------------

--If one operand is a string and the other is not, JavaScript converts the non-string value into a string and performs concatenation.

Example:

console.log("The number is " + 5);

Output:

The number is 5

Another Example:

console.log("10" + 20);

Output:

1020


Numeric Conversion:
-------------------

--Arithmetic operators such as -, *, /, and % try to convert operands into numbers.

Example:

console.log("10" - 2);

Output:

8

Example:

console.log("10" * 2);

Output:

20

Example:

console.log("apple" - 2);

Output:

NaN


Boolean Conversion:

--In conditional statements, JavaScript converts values into boolean values.

The following values are considered Falsy:

false
0
""
null
undefined
NaN

Example:

if(0){
    console.log("Hello");
}
else{
    console.log("Hi");
}

Output:

Hi


2. Explicit Type Conversion (Manual Coercion):
-----------------------------------------------

--JavaScript provides built-in functions to manually convert values from one type to another.

Convert to String:

Use the String() function.

Example:

let str = String(num);

or

let str = 123+"";


console.log(str);
console.log(typeof str);

123
string

Example:

console.log(Number(true));

0

package.json:
-------------

--The package.json file contains information about the project.

It stores:

Project Name
Project Version
Project Description
Dependencies used in the project
Scripts and configuration settings

--It is like pom.xml file in maven project

Example:

{
  "name": "javascript-demo",
  "version": "1.0.0",
  "dependencies": {
    "prompt-sync": "^4.2.0"
  }



Notice the ^ symbol.

It means:

I need version 4.2.0 or any compatible newer version.

--Install version 4.2.0 or any compatible update
without changing the major version.

Allowed:

4.2.1
4.3.0
4.5.7
4.9.0

Not Allowed:

5.0.0

because the major version changed from 4 -> 5.


Tomorrow prompt-sync team releases:

4.2.1
4.2.2
4.2.4

Another developer on your team executes:

npm install

he might get:

prompt-sync 4.2.2

while you are using:

prompt-sync 4.2.0

Now both machines have different versions.

This can create bugs.



package-lock.json solves this problem




package-lock.json:
------------------

--The package-lock.json file is automatically generated by npm.

It stores the exact versions of all installed packages and their dependencies.

Purpose:

Ensures consistent installations across different systems.
Helps all developers use the same package versions.

Think of it as a detailed installation record of the project.


This file says:

Don't install any other version.

create a function that accept both arrays as parameter and return an object in which element of first array are keys and elements of second array are values.

{
	'English': 67,
	'Hindi': 76,
	'Physics': 77,
	'Chemistry': 66,
	'Maths': 89
}

----------


function getObject(sub, mk) {
  //Empty object
  let obj = {};

  //iterate on each element of the array
  for (let i = 0; i < sub.length; i++) {

    //adding one entry inside the object
    obj[sub[i]] = mk[i];
  }

  return obj;
}







function foo() {

  let subjects = ['English', 'Hindi', 'Physics', 'Chemistry', 'Maths']
  let marks = [67, 76, 77, 66, 89]

  let object = getObject(subjects, marks);

}

Object creation with Factory function:
======================================


Factory function:
-----------------

--A factory function is a function that returns an object. 
--It allows for the creation of multiple instances of objects with the same structure, without the need for a constructor function or class. 
--The main advantage of a factory function is that it provides more flexibility than using constructors or classes.


Characteristics:
---------------
--A factory function does not use the new keyword.
--It can return different objects each time it’s called.


Example1:


function createStudent(roll, name, marks){

let obj={};

obj.roll= roll;
obj.name= name;
obj.marks= marks;

return obj;

}


--creating student object based on the above factory function.


let s1 = createStudent(10,"Rahul",800);

console.log(s1);



Factory function to create an object with a method/function:
------------------------------------------------------------



function createStudent(roll, name, marks){

    let obj={};
    
    obj.roll= roll;
    obj.name= name;
    obj.marks= marks;

    obj.introduce= function(){
        console.log("Inside the introduce function");
        console.log("Roll is", this.roll);
        console.log("Name is", this.name);
        console.log("Marks is", this.marks);
    }
    
    return obj;
    
    }
    

    let s1 = createStudent(10,"Rahul",800);

    s1.introduce();






Object Creation with Constructor function:
===========================================

Constructor Function:
---------------------

--A constructor function is used to create objects in JavaScript similar to the factory function, but here we need to make use of "new" keyword.

--Here we need not create any object inside the function explicitly and need not return any object from this constructor function. 

--Constructor function name typically starts with an uppercase letter to follow the convention of capitalizing constructor names.


Example:



function Student(roll, name, marks){

    this.roll= roll;
    this.name= name;
    this.marks= marks;

    this.introduce= function(){
        console.log("Inside the introduce function");
        console.log("Roll is", this.roll);
        console.log("Name is", this.name);
        console.log("Marks is", this.marks);
    }
    
    }
    

    let s1 = new Student(10,"Rahul",800);

    console.log(s1);
    s1.introduce();




Object creation with class:
============================

--A class is a template for creating objects. 
--Classes were introduced in ECMAScript 6 (ES6) and provide a syntactic sugar over constructor functions. 
--Classes can have constructors and methods defined within them.

Example:


class Student{

    constructor(roll, name, marks){
        this.roll=roll;
        this.name=name;
        this.marks= marks;
    }


    introduce(){
        console.log("Inside the introduce function");
        console.log("Roll is", this.roll);
        console.log("Name is", this.name);
        console.log("Marks is", this.marks);
    }



}

s1.introduce();

Difference Between JavaScript Object and JSON:
==============================================

JavaScript Object			JSON

Used inside JavaScript programs		Used for data exchange

Keys may be quoted or unquoted		Keys must be enclosed in double quotes

Can contain functions			Cannot contain functions

Can be directly manipulated		Usually transferred as text

JavaScript specific			Language independent







JSON.stringify():
=================

--The JSON.stringify() method converts a JavaScript Object into a JSON String.

Syntax:

JSON.stringify(object)



Example


let user = {
    id: 101,
    name: "Ram",
    email: "ram@gmail.com"
};

let jsonData = JSON.stringify(user);

console.log(jsonData);
console.log(typeof jsonData);

Output:

{"id":101,"name":"Ram","email":"ram@gmail.com"}
string



Why Do We Need It?

When sending data to:

REST APIs
Backend Servers
Files
Local Storage

--the data is often converted into JSON format before transmission.


JSON.parse():
==============

--The JSON.parse() method converts a JSON String back into a JavaScript Object.

Syntax:

JSON.parse(jsonString)


Example:

let jsonData = '{"id":101,"name":"Ram","email":"ram@gmail.com"}';

let user = JSON.parse(jsonData);

console.log(user);

console.log(user.name);

Output:

{ id: 101, name: 'Ram', email: 'ram@gmail.com' }
Ram
