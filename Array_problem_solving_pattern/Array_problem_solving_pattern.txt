What is an Array?
------------------

--An Array is a collection of elements of the same data type stored in contiguous memory locations.

int[] arr = {10, 20, 30, 40, 50};


Memory Representation


Value : 10   20   30   40   50
Index :  0    1    2    3    4

All values are stored continuously in memory.

This allows very fast access to any element.



Advantages:

Fast access: index based
Easy traversal
Cache friendly



Array Access is O(1):
---------------------


Example:

System.out.println(arr[3]);

--The JVM can directly calculate the memory location of the required element using its index.

--No searching required.


Example:

arr[0]
arr[50]
arr[999]

--All of the above operations take approximately the same amount of time.

Therefore:

Access Time Complexity = O(1)


--This is one of the biggest advantages of Arrays.




Traversing an Array:
--------------------

--Traversal means visiting every element of the array one by one.

--There are several ways to traverse an array.



Example 1: Using normal for loop

int[] arr = {10,20,30,40,50};

for(int i=0;i<arr.length;i++){
    System.out.println(arr[i]);
}



Example2: Using enhanced for loop


for(int i: arr){

System.out.println(i);

}


Example3: Using a while loop

int[] arr = {10, 20, 30, 40, 50};

int i = 0;

while(i < arr.length){
    System.out.println(arr[i]);
    i++;
}



Example4: Using a do-while loop:


int[] arr = {10, 20, 30, 40, 50};

int i = 0;

do{
    System.out.println(arr[i]);
    i++;
}while(i < arr.length);


Example 5: Traversing in Reverse Order:

int[] arr = {10, 20, 30, 40, 50};

for(int i = arr.length - 1; i >= 0; i--){
    System.out.println(arr[i]);
}


Example 6: Using Java Streams (Java 8+)


import java.util.Arrays;

int[] arr = {10, 20, 30, 40, 50};

Arrays.stream(arr)
      .forEach(System.out::println);


Example 7: Using Arrays.toString() (Not Actual Traversal)

int[] arr = {10, 20, 30, 40, 50};

System.out.println(Arrays.toString(arr));


Note: This is not actual traversal from the programmer's perspective.

--Internally, Java traverses the array to generate the string representation, but we do not get access to individual elements.


Example 8: Recursive Traversal

public static void traverse(int[] arr, int index){

    if(index == arr.length){
        return;
    }

    System.out.println(arr[index]);

    traverse(arr, index + 1);
}

Calling:

traverse(arr, 0);

The Biggest Limitation of Arrays:
--------------------------------


--Arrays are fast.

--However, arrays are not flexible because their size is fixed once created.


Example:


If we have:

int[] arr = {10,20,30,40,50};

then the array length is fixed at 5.

Index : 0   1   2   3   4
Value : 10  20  30  40  50

--There is no extra space available to store another element.

If you try:

arr[5] = 60;

you will get:

ArrayIndexOutOfBoundsException

--because valid indexes are only 0 to 4.


So how do we insert 25?

for(int i=0;i<position;i++){

public static int[] insertElementAtIndex(int[] arr,int value,int index){

    int[] newArr = new int[arr.length+1];

    for(int i=0;i<index;i++){
        newArr[i] = arr[i];
    }

    newArr[index] = value;

    for(int i=index;i<arr.length;i++){
        newArr[i+1] = arr[i];
    }

    return newArr;
}




Deleting an Element from an Array:
==================================

--Arrays should not contain gaps.

Suppose:

10 20 30 40 50

Delete:

30

After deletion:

10 20 _ 40 50

--The gap must be filled by shifting elements to the left.


Case 1: Delete from Beginning

Suppose:

10 20 30 40 50

Delete:

10

Expected Output:

20 30 40 50


Step1: 

--Create a new array of size n - 1.


Step2: 

--Copy all elements except the first.


int[] arr = {10,20,30,40,50};

int[] newArr = new int[arr.length-1];

for(int i=1;i<arr.length;i++){
    newArr[i-1] = arr[i];
}



Time Complexity: O(n)
Space Complexity: O(n)

Suppose:

Delete:

50

Expected Output:

10 20 30 40


Step1: 

--Create a new array of size n - 1.

Step2: 

--Simply copy all elements except the last.


int[] arr = {10,20,30,40,50};

int[] newArr = new int[arr.length-1];

for(int i=0;i<arr.length-1;i++){
    newArr[i] = arr[i];

Case 3: Delete from a Specific Index

Suppose:

10 20 30 40 50

Delete element at index:

2

Expected Output:

10 20 40 50


Implement the following method:


public static int[] deleteAtIndex(int[] arr,int index)




Step1: 

--Create a new array of size n - 1.

Step 2:

--Copy elements before the deletion index.

for(int i=0;i<index;i++){
    newArr[i] = arr[i];
}


Step 2

--Skip the deleted element and copy remaining elements.


for(int i=index+1;i<arr.length;i++){
    newArr[i-1] = arr[i];
}


final solution:
---------------

public static int[] deleteAtIndex(int[] arr,int index){

    int[] newArr = new int[arr.length-1];

    for(int i=0;i<index;i++){
        newArr[i] = arr[i];
    }

    for(int i=index+1;i<arr.length;i++){
        newArr[i-1] = arr[i];
    }

    return newArr;
}




Note: For deletion, creating another array is not always required.

There are actually two approaches for deletion from an array:

1. The above approach, by creating a new array.

2. Delete In-Place (No New Array)

--With Delete In-Place the space complexity will become O(1)

--In a fixed-size Java array, you cannot truly remove an element and reduce the array's length.

--because array length is immutable.

You can only:

--Shift elements and maintain a logical size

--That's exactly why classes like ArrayList were introduced. They hide all this resizing logic from the programmer.

--This is the technique used internally by many array-based data structures.


Example:


int[] arr = {10,20,30,40,50};

int size = 5;

int index = 2; // delete 30


Shift elements to the left:

for(int i=index;i<size-1;i++){
    arr[i] = arr[i+1];
}

size--;


Physical array becomes:

10 20 40 50 50

But logically:

10 20 40 50

because size = 4.

Printing:

for(int i=0;i<size;i++){
    System.out.print(arr[i] + " ");
}



Output:

10 20 40 50

Complexity

Time  : O(n)
Space : O(1)

Solution
---------

int largest = Integer.MIN_VALUE;
int secondLargest = Integer.MIN_VALUE;

for(int num : arr){

    if(num > largest){

        secondLargest = largest;
        largest = num;
    }
    else if(num > secondLargest && num != largest){

        secondLargest = num;
    }

System.out.println(secondLargest);

Two Pointer technique:
======================

--In Java, a pointer simply means an index variable.

--The Two Pointer Technique is a problem-solving approach where we use two variables (pointers/indexes) to traverse a data structure, usually an array or string.

--Instead of using nested loops, we often use two pointers to process data more efficiently.

--Often reducing the time complexity from O(n2) to O(n).


Example

int[] arr = {10,20,30,40,50};

int left = 0;
int right = arr.length - 1;

Here:

left  -> points to first element
right -> points to last element

Visualization:

Index : 0   1   2   3   4
Value :10  20  30  40  50
        ↑              ↑
      left           right


Consider this problem:

--Find if a sorted array contains two numbers whose sum is 70.


int[] arr = {10,20,30,40,50};



Brute Force Approach:
--------------------

--Check every pair.

for(int i=0;i<arr.length;i++){

    for(int j=i+1;j<arr.length;j++){

        if(arr[i] + arr[j] == 70){
            System.out.println("Found");
        }
    }
}


Time Complexity = O(n²)

--For large arrays, this becomes slow.



Idea Behind Two Pointers:
-------------------------

--Instead of checking every pair:

10 20 30 40 50
 ↑           ↑
left      right

Check:

10 + 50 = 60

Too small?

--Move left forward.

20 + 50 = 70

Found.

--Only a few comparisons were needed.

Complexity: O(n)

--Much better than O(n²).

Types of Two Pointer Technique:
===============================

--There are two major patterns.

Type 1: Opposite Direction
----------------------------

--Pointers start from opposite ends.

--Usually used when the array is sorted



left        right
 ↓           ↓
10 20 30 40 50

Usually used for:

Pair Sum
Reverse Array
Palindrome
Container With Most Water



Type 2: Same Direction
----------------------

--Both pointers move from start to end, useful in sliding window or prefix sum type problems.

slow
 ↓
fast
 ↓

--Usually used for:

Misconceptions:
---------------

--"Two pointers only work on sorted arrays" - False. It works best for opposite direction problems if the array is sorted. For same direction, array need not be sorted (e.g., sliding window, subarrays).


Problem 1: Reverse an Array:
----------

--Reverse the array without using another array.

  public static void reverse(int[] arr)


IDEA:

[10,20,30,40,50]

--Swap first and last element.

10 <--> 50
20 <--> 40

Move both pointers toward center.


Solution:

 public static void reverse(int[] arr){

        int left = 0;
        int right = arr.length - 1;

        while(left < right){

            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;

            left++;
            right--;
        }
    }


Problem 2: Check Palindrome String

--A palindrome reads the same from both directions.

Examples:

madam

racecar


public static boolean isPalindrome(String str)


IDEA:

Compare:

First character
Last character

If equal:

Move inward

If not equal:

Not palindrome


Solution:
---------

 public static boolean isPalindrome(String str){

        int left = 0;
        int right = str.length() - 1;

        while(left < right){

            if(str.charAt(left) != str.charAt(right)){
                return false;
            }

            left++;
            right--;
        }

        return true;
    }



Problem 3: Pair Sum in Sorted Array:

--Find if there exist two numbers in a sorted array that sum up to the target.

Input: int[] arr = {10,20,30,40,50}, target = 70

Output: true (20 + 50)

public static boolean pairSum(int[] arr,int target)



Solution:

public static boolean pairSum(int[] arr,int target){

    int left = 0;
    int right = arr.length - 1;

    while(left < right){

        int sum = arr[left] + arr[right];

        if(sum == target){
            return true;
        }
        else if(sum < target){
            left++;
        }
        else{
            right--;
        }
    }

    return false;
}


Complexity:

Time  : O(n)
Space : O(1)

Without Two Pointers: O(n²)



Binary Search using 2 pointer:
------------------------------

--Binary Search also uses a form of two pointers.


The two pointers are:

low
high

--These pointers represent the current search range.

Example:

int[] arr = {10,20,30,40,50,60,70,80,90};

int target = 60;

Initially:

Index : 0  1  2  3  4  5  6  7  8
Value :10 20 30 40 50 60 70 80 90
        |                       |
       low                     high
     


Example:


public static int binarySearch(int[] arr, int target) {

    int low = 0;
    int high = arr.length - 1;

    while(low <= high) {

        int mid = low + (high - low) / 2;

        if(arr[mid] == target) {
            return mid;
        }
        else if(arr[mid] < target) {
            low = mid + 1;
        }
        else {
            high = mid - 1;
        }
    }

    return -1;
}



Note: Even though Binary search uses a two pointer technique (2 indexes low and high) to define a search range, However, in DSA, when people say "Two Pointer Technique", they usually mean:

left/right moving toward each other
or
slow/fast moving together

-Binary Search uses two boundary indexes (low and high).

--But in DSA interviews, Binary Search and Two Pointer Technique are usually treated as different patterns.

Problem 4: Separate 0s and 1s
------------------------------


Input:

[0,1,0,1,1,0,0,1]

Output:

[0,0,0,0,1,1,1,1]


Idea:

--Left pointer searches for 1: left should stop on a wrong 1.

--Right pointer searches for 0: right should stop on a wrong 0.

When found: Swap


public static void separate(int[] arr)





Solution:
---------

 public static void separate(int[] arr){

        int left = 0;
        int right = arr.length - 1;

        while(left < right){

            while(left < right && arr[left] == 0){
                left++;
            }

            while(left < right && arr[right] == 1){
                right--;
            }

            if(left < right){ //prevents this unnecessary swap.

                int temp = arr[left];
                arr[left] = arr[right];
                arr[right] = temp;

                left++;
                right--;
            }
        }
    }



Time Complexity = O(n)

Space Complexity = O(1)


Problem 5: Given a sorted array, remove duplicates in-place and keep only unique elements.

Input

int[] arr = {1,1,2,2,2,3,4,4,5};

Output

1 2 3 4 5


We use:

slow pointer
fast pointer

Responsibilities: 

slow

--Points to the last unique element.

fast

--Scans the array.

Example

int[] arr = {1,1,2,2,2,3,4,4,5};

Initial:

1 1 2 2 2 3 4 4 5
S F




Step 1

Move fast.

1 1 2 2 2 3 4 4 5
S F

Compare:

arr[slow] == arr[fast]


1 == 1

Duplicate found. 

Do nothing.



Step 2

Move fast.

1 1 2 2 2 3 4 4 5
S   F

Compare:

1 != 2

New unique element found.

Move slow forward.

slow++;


Copy:

arr[slow] = arr[fast];

Array becomes:

1 2 2 2 2 3 4 4 5
  S
      F


Step 3

Fast moves.

1 2 2 2 2 3 4 4 5
  S F

Duplicate.

Ignore.


Step 4

Fast moves.

1 2 2 2 2 3 4 4 5
  S   F

Duplicate.

Ignore.


Step 5

Fast reaches 3.

1 2 2 2 2 3 4 4 5
  S       F

New value.

Move slow.

1 2 3 2 2 3 4 4 5
    S     F


Continue similarly.

Final array:

1 2 3 4 5 _ _ _ _

Unique count:

--slow will point to the last index 

Final element count = slow+1;




Example:

public static int removeDuplicates(int[] arr){

    if(arr.length == 0){
        return 0;
    }

    int slow = 0;

    for(int fast = 1; fast < arr.length; fast++){

        if(arr[slow] != arr[fast]){

            slow++;

            arr[slow] = arr[fast];
        }
    }

    return slow + 1;
}

Subarray:
==========

--A subarray is a contiguous (continuous) part of an array.


Important points:

--Elements must be adjacent.
--Order remains the same.
--A subarray is defined by a start index and an end index.
--Every subarray occupies a continuous range of indexes.

Example:

int[] arr = {1, 2, 3};


Possible subarrays:

[1]
[2]
[3]

[1,2]
[2,3]

[1,2,3]

Invalid Subarray:

[1,3]

Because 2 is skipped.

--A subarray must be continuous.



Total Number of Subarrays:

--For an array of length n: ==> n*(n+1)/2 subarrays.

Example:

Array: [1, 2, 3] ->  n=3

Total subarrays = 3*(3+1)/2 = 6




Subsequence:
-----------

--Elements may not be contiguous, but the order is preserved.

Example:

For arr = [1, 2, 3]

Possible subsequences:

[], [1], [2], [3]

[1,2], [1,3], [2,3]

[1,2,3]

--All subarrays are subsequences, but not all subsequences are subarrays.





Subset:
-------

--A subset is any combination of elements from a set or array without considering the order and regardless of their position.

--Order does NOT matter

--Indexes do NOT matter


Example:

For arr = [1, 2, 3]

Subsets:

{}, {1}, {2}, {3}

{1,2}, {1,3}, {2,3}

{1,2,3}


--In DSA problems, subsets and subsequences sometimes overlap, but mathematically, they are different. 

--Total subsets of size n is 2^n

public static int maxSubArray(int[] arr){

    int currentSum = 0;
    int maxSum = Integer.MIN_VALUE;

    for(int num : arr){

        currentSum += num;

        maxSum = Math.max(maxSum, currentSum);

        if(currentSum < 0){

        }
    }

    return maxSum;

Add the new thing.

This idea is called the Sliding Window Technique.

Approach 2: Sliding Window
---------------------------


Step 1

--Calculate the first window sum.
--store it in windowSum variable.


Step 2

--Move the window one step right.
--Remove the outgoing element
--Add the incoming element


Whenever the window moves:

newWindowSum = oldWindowSum - outgoingElement + incomingElement





public class Demo {

    public static void main(String[] args) {

        int[] arr = {2, 3, 4, 5, 6};

        int k = 2;

        int windowSum = 0;

        // First Window Sum

        for (int i = 0; i < k; i++) {
            windowSum += arr[i];
        }

        System.out.println(windowSum);

        // Slide Window

        for (int i = k; i < arr.length; i++) {

            windowSum =
                    windowSum
                    - arr[i - k]
                    + arr[i];

            System.out.println(windowSum);
        }
    }
}

Step 2:
Slide window across remaining elements: O(n-k)

Total: O(k + n-k) = O(n)
